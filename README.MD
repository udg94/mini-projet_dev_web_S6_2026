## Installation des dépendances

Pour lancer le projet, placez-vous dans le dossier contenant package.json, puis exécutez la commande :

```bash
npm install
npm run dev
```
## Lancer le projet
Pour démarrer le projet, utilisez la commande :

```bash
npm run dev
```
Ensuite, rendez-vous à l’adresse locale affichée dans le terminal (par exemple : http://localhost:5173).
